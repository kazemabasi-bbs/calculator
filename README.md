# ماشین حساب (اپ اندروید)

1. همه‌ی فایل‌های این پوشه را در یک مخزن گیت‌هاب آپلود کنید (شاخه‌ی main).
2. به تب Actions بروید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow را بزنید).
3. پس از سبز شدن، وارد اجرای ساخت شوید و از بخش Artifacts فایل `calculator-apk` را دانلود کنید.
4. فایل zip را باز کنید و `app-debug.apk` را روی گوشی نصب کنید (اجازه‌ی نصب از منبع ناشناس لازم است).

تغییر نام بسته: مقدار `appId` در `capacitor.config.json`.
ویرایش برنامه: فقط `www/index.html`.
